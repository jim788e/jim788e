### 🚀 What I'm building: Multiscraper (*Instagram, TikTok & Google Business Exporter*)

A powerful **Manifest V3 Chrome Extension** that exports complete profile data and media with zero paywalls. Runs directly inside your authenticated browser session to extract full feeds, verified engagement counts, reviews, and high-res media.

[![Version](https://img.shields.io/badge/version-v1.0.0-blue?style=flat-square)](https://github.com/jim788e/Multiscraper/releases)
[![License: MIT](https://img.shields.io/badge/license-MIT-green?style=flat-square)](https://github.com/jim788e/Multiscraper/blob/main/LICENSE)
[![Stars](https://img.shields.io/github/stars/jim788e/Multiscraper?style=flat-square&color=181717&logo=github)](https://github.com/jim788e/Multiscraper)

- 📸 **Instagram:** Full profile exports with real like/comment counts & batch media downloads (photos & videos) using first-party session feeds.
- 🎵 **TikTok:** Intercepts native signed API calls via automated profile scroll capture for complete video feeds.
- 📍 **Google Business & Maps:** Extracts metadata (hours, category, rating, address) and paginates through all user reviews with auto-translations into JSON, CSV, or Markdown reports.
- 💾 **Silent Batch Downloads:** Automated background saving to organized subfolders with zero per-file prompts.
